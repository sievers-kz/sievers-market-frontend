## Решения, которые не видны из кода
- **Сессия и прокси.** Бэкенд ставит cookie без `Domain`. Браузер ходит на свой origin `/api/v1/...`, rewrite в `next.config.ts` ведёт на `BACKEND_URL` (серверная переменная, читается при сборке; нужна в `.env.local` и в Vercel). Путь ровно `/api/v1`: refresh-cookie стоит с `Path=/api/v1/iam`. Нужен `skipTrailingSlashRedirect` (у части путей API слэш на конце). Сервер Next ходит на `BACKEND_URL` напрямую и пробрасывает `Cookie`.
- **Токен на сервере не обновляется** (Server Component не ставит cookie): `getCurrentUser()` при 401 даёт `null`. Single-flight refresh работает только в браузере. Серверное обновление через `proxy.ts` отложено.
- **`getCurrentUser()`** принимает `role: null` и `"None"` как «роли нет» (backend#204). Роль читается из БД, а не из токена: после создания профиля токен обновлять не нужно.
- **`NEXT_PUBLIC_API_URL`** остаётся только для картинок (`getMediaUrl`, `images.remotePatterns`).
- **Ошибки.** Бэкенд отдаёт `{error_code, message, detail, metadata}`; `metadata.field` это имя поля запроса. Ошибки Pydantic (422 `{detail: [{loc, msg}]}`) обрабатываем сырыми, без единого формата на бэкенде. Идея на потом: словарь `error_code → текст` с запасным `message` (в `error-codes.ts`).
- **Тип продавца.** В интерфейсе только «Физическое лицо» / «Юридическое лицо». Временное соответствие `legal_form`: физлицо → `IE`, юрлицо → `LLP` (backend#213).
- **Радио-плитки** (`TileRadioGroup`) сделаны настоящими `input type="radio"`; выбор не переключает шаг, дальше ведёт кнопка «Продолжить».
- **Правила пароля:** 8-64 символа (регистрация); код подтверждения 6 цифр, живёт 5 минут; повтор не раньше чем через 60 секунд (на фронтенде константа, backend#203).

## Известные ограничения и долги
- Кнопки выхода и шапки пока нет (спека: `docs/pages/header.md`).
- Вход и регистрация могут потерять 422 с полем вне формы (в онбординге это решено опцией `fields` в `showFormError`).
- Тупик на шаге кода при закрытой странице (backend#202).
- Мелкие визуальные правки после онбординга: тип и номер продавца на одном экране, иконки, плотность таблицы «Это ваша организация?», кнопка «Зарегистрироваться» неактивна до согласия.
- Картинки объявлений не видны: бэкенд подписывает ссылки внутренним хостом MinIO (backend#208).
- Тестов в проекте нет.
- Vercel не подключён.
