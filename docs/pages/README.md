# Спецификации экранов

Один файл на экран: `docs/pages/<экран>.md`. Агент читает его перед началом работы.

Шаблон:

```md
# Название экрана
- Маршрут: `/...`
- Доступ: все / customer / vendor
- Макет: ссылка на Figma-фрейм
- Данные: операции API (operationId), параметры, кэширование
- Состояния: загрузка, пусто, ошибка, нет доступа
- Поведение: действия пользователя и переходы
- Заметки: нюансы, отличия от макета
```

Первым пишем `catalog.md` — эталонный экран.
