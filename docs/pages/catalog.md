# Каталог (список объявлений)

- **Маршрут:** `/catalog/[...]` — точная схема URL открыта, см. «Вопросы» ниже. Пока ориентир: `/catalog?category=<id>&subcategory=<id>&page=1&…фильтры`.
- **Доступ:** все, без авторизации.
- **Макет:** Figma «AGROW», страница 1. Фреймы `672:206` (плитка), `672:2` (список). Это **визуальный ориентир**, а не источник размеров: числа в макете не по сетке 8pt, подгоняй под токены проекта.
- **Рендер:** Server Component. Состояние фильтров живёт в URL (`searchParams`), чтобы страницу можно было открыть по ссылке и работал SSR.

## Структура экрана (десктоп 1440)
1. Шапка: логотип, строка поиска, кнопка «Подать объявление» (общий компонент `layout`, не часть экрана).
2. Хлебные крошки: Главная / Каталог / Техника.
3. Заголовок: название выбранной категории (например «Тракторы»).
4. Две колонки в `Container`:
   - **Сайдбар фильтров** (~308px): карточки-аккордеоны. Раскрытые: подкатегории (чекбоксы), «Цена, ₸» (от/до + слайдер), «Регион» (чекбоксы). Свёрнутые: «Марка», «Состояние», «Год выпуска», «Мощность двигателя», «Объём двигателя». Состав атрибутов берётся из API (`getSubcategoryFilters`), а не зашит в код.
   - **Контент:** панель «Найдено объявлений: N», сортировка, переключатель вида (плитка / список); ниже строка чипов активных фильтров с крестиком и кнопкой «Сбросить фильтры»; сетка карточек; пагинация (стрелки + номера страниц).
5. Фон страницы светло-серый, блоки белые с крупным скруглением.

## Карточка объявления
- **Плитка (3 колонки):** фото с индикатором слайдов и кнопкой «в избранное» (сердечко), бейджи, название, продавец или категория, цена, город.
- **Список:** фото слева, справа бейджи, название, «Категория: …», «Продавец: …», цена справа вверху, внизу город и дата.
- **Цена:** число + валюта; для «Договорная цена» / «Цена по запросу» показывать текст. Для услуг цена с единицей («₸, в/ч»).
- Бейджи (цветные): «Новый» / «Б/у» (серый), «Аренда» (синий), «Спец. предложение» (зелёный), «Услуги» (контурный жёлтый).

## Данные (операции API)
| Что | operationId | Примечание |
|---|---|---|
| Дерево категорий (подкатегории в сайдбаре, крошки) | `getCategoryTree` | сервер, `next: { revalidate }` |
| Атрибуты-фильтры подкатегории | `getSubcategoryFilters` | сервер |
| Города | `getAllCities` | сервер, `revalidate` |
| Список без текстовых фильтров | `getListingsCatalog` | `category_id` обязателен; `subcategory_id`, `page`, `limit` |
| Список с фильтрами и текстом | `searchListing` | `text`, `subcategory_id`, `city_id`, `price_min/max`, `attributes`, `page`, `limit` |

`ListingCardResponse`: `id`, `display_owner_name`, `subcategory`, `title`, `price`, `currency`, `city`, `preview_image` (uuid).

## Состояния
- Загрузка: `loading.tsx` со скелетонами карточек.
- Пусто: «Ничего не найдено» + кнопка «Сбросить фильтры».
- Ошибка API: `error.tsx` с повтором.
- Невалидная категория: `notFound()`.

## Поведение
- Изменение любого фильтра обновляет URL и сбрасывает страницу на 1.
- Чип с крестиком снимает один фильтр; «Сбросить фильтры» очищает все.
- Переключатель плитка/список хранится в URL (`view=grid|list`) или cookie — выбери проще, отметь в PR.
- Пагинация: из `pages` и `page` ответа.
- На мобильных: сайдбар уходит в выдвижную панель по кнопке «Фильтры», карточки в одну колонку. Мобильного макета для каталога нет, делай по общим правилам.

## Расхождения макета и API (решить до или в процессе работы)
Не придумывай, а отмечай в PR, что показал заглушкой или пропустил.
1. **Бейджи** («Новый», «Аренда», «Спец. предложение», «Услуги») и **дата публикации** отсутствуют в `ListingCardResponse`.
2. **Сортировка** («Сначала новые» и т. д.) не поддерживается ни одним методом списка.
3. **Регион** в макете, а в API только города (`city_id`).
4. **Картинки:** в карточке только `preview_image` (uuid медиа). Как получить URL файла, неясно: `getMedia` описан как «метаданные или редирект», а тип ответа не задан (`unknown`).
5. **Ответ `searchListing`** не типизирован (`unknown`), структура пагинации предположительно как у `getListingsCatalog`. Нужна схема на бэкенде.
6. **Избранное** (сердечко) в API нет: пока декоративно или скрыть.
7. Название бренда в шапке макета: Altum Market, а продукт называется Sievers Market. Уточнить.
