# Шапка сайта (хедер)

- **Компонент:** `SiteHeader`, `src/components/layout/`. Показывается на всех страницах сайта (каталог, главная, служебные), кроме страниц входа, регистрации и онбординга: там только логотип со ссылкой на `/`, без блока пользователя и без меню.
- **Доступ:** все; содержимое правой части зависит от `getCurrentUser()`.
- **Макет:** Figma «AGROW», страница 1, фрейм `739:9` (ключ файла у владельца; без доступа к Figma делай по описанию ниже). Макет это **визуальный ориентир**, размеры по сетке 8pt и токенам. В макете шапка показывает имя пользователя и уже на экране регистрации: это артефакт, не повторяй.
- **Рендер:** Server Component, который читает пользователя через `getCurrentUser()`.

## Главное ограничение
Шапка **не должна делать весь сайт динамическим**. Каталог и главная должны остаться кешируемыми (`revalidate`, как в `docs/pages/catalog.md`), иначе теряем кеш и SEO. Для этого блок пользователя читает сессию отдельно от остальной страницы (граница `Suspense` с заглушкой нужной высоты, без прыжка вёрстки) или решение через клиентский компонент. **Перед работой прочитай документацию Next 16 в `node_modules/next/dist/docs/`** (cookies в layout, Suspense, режимы рендера), выбери вариант и опиши в PR. Проверка: в выводе `npm run build` у страниц каталога и главной не должно появиться знака динамического рендера (ƒ), если до шапки его не было.

## Состав
Слева логотип «Sievers Market» (ссылка на `/`). Основная навигация в этом PR не делается (мега-меню отдельной спецификацией). Справа блок пользователя.

## Блок пользователя по состояниям
| Состояние | Что показывать |
|---|---|
| Гость (`getCurrentUser()` → `null`) | ссылка «Вход» (`/login`) и кнопка «Регистрация» (`/register`) |
| Нет роли (онбординг не пройден, `role: null`) | кнопка «Завершить профиль» (`/onboarding`) и «Выйти» |
| `customer` | аватар, по клику меню |
| `vendor` | аватар, по клику меню |

**Аватар:** круг с инициалами (покупатель: `last_name` и `first_name` из `profile`; продавец: `contact_last_name` и `contact_first_name`). Если имени нет, иконка пользователя. Кнопка с `aria-label` (например, «Меню пользователя»).

**Меню (dropdown):** открывается **по клику**, не при наведении (на телефоне наведения нет). Закрывается по Esc, клику вне, выбору пункта. Фокус и клавиатура работают как у настоящего меню (стрелки, Enter). Компонент `dropdown-menu` из shadcn (`npx shadcn add dropdown-menu`; Radix уже разрешён, новых пакетов добавлять не нужно).

Состав меню растёт вместе с экранами. Пункт добавляется, только когда страница существует (не показывай ссылки в пустоту):
| Пункт | Роль | Когда добавить |
|---|---|---|
| Выйти | все с ролью (и без) | **сейчас** |
| Личный кабинет | customer, vendor | с экраном кабинета |
| Мои объявления | vendor | с экраном кабинета продавца |
| Создать объявление | vendor | с экраном создания |

## Выход
Кнопка «Выйти» вызывает `logoutUser()`. После ответа: перенаправление на `/` и `router.refresh()`, чтобы шапка и серверные компоненты увидели гостя. Ошибку выхода (сеть, 401) не показывай как проблему: сессия в любом случае считается завершённой на клиенте, пользователь попадает на `/` как гость. Во время запроса кнопка заблокирована.

## Адаптивность (mobile-first)
На узком экране шапка в одну строку: логотип слева, аватар или кнопки справа. Если кнопки гостя не помещаются, «Вход» остаётся ссылкой, «Регистрация» кнопкой меньшего размера. Меню по ширине не выходит за экран.

## Состояния
Загрузка блока пользователя: заглушка (круг или две серые полосы той же высоты). Ошибка `getCurrentUser()` (не 401): считать гостем и не ломать страницу; не показывать ошибку в шапке.

## Вне объёма (не делать сейчас)
Поиск, избранное, переключатель языка, мега-меню, уведомления, счётчики.

## Расхождения (не придумывать, описать в PR)
1. Если макет показывает в шапке элементы, которых здесь нет (поиск, избранное), не добавляй их, перечисли в PR.
2. Обновление токена на сервере (`proxy.ts`) пока нет: после истечения access-cookie (30 минут) шапка показывает гостя, пока пользователь не вошёл снова. Это известное ограничение, не чини.
