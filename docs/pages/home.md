# Главная страница

- **Маршрут:** `/` (`src/app/(site)/page.tsx`, сейчас заглушка).
- **Доступ:** все, без авторизации.
- **Макет:** Design-артефакт «Sievers Market: главная страница», варианты `Главная · рубрики 5, «Как это работает», контакты` (десктоп, **утверждён**) и `Телефон · по варианту 4` (мобильная). Снимки лежат рядом: `docs/pages/home-assets/mockup-desktop.png`, `mockup-mobile.png` (на снимках логотип в шапке не загрузился, это артефакт рендера, шапку не трогаем). Макет это визуальный ориентир: размеры подгоняй под сетку 8pt, цвета только токенами (SVG-файлы из `home-assets/` исключение, они копируются как есть).
- **Рендер:** Server Component, кэш `export const revalidate = 60`. Клиентского кода на странице нет (поиск в hero неактивен, анимации в SVG средствами SMIL).
- **Заголовок и описание (metadata):** `title: { absolute: "Sievers: маркетплейс сельхозтехники и оборудования в Казахстане" }`, `description` из `SITE_DESCRIPTION`, `openGraph` с теми же `title` и `description`. Картинку Open Graph (1200×630) и favicon делаем отдельной задачей, в этот PR не входят.

## 1. Hero
Секция `relative overflow-hidden bg-hero`. Линии это **готовый SVG**: `docs/pages/home-assets/hero-desktop.svg` (на `xl`+) и `hero-mobile.svg` (ниже `xl`). Это нарисованный каркас страницы: перекладина и V из семи параллельных линий, сетка клеток, бегущие точки. **Не перерисовывай и не меняй числа**: перенеси содержимое в компонент `HeroLines` (`src/components/home/hero-lines.tsx`) как JSX, заменив только имена атрибутов на camelCase (`stroke-width` → `strokeWidth`, `stop-color` → `stopColor`, `xlink:href`/`href` у `mpath` оставь `href`). Требования:
- Корневой `<svg>` с `aria-hidden="true"`, `focusable="false"`, `className="pointer-events-none absolute left-0 top-0 h-full w-full"`, `preserveAspectRatio="xMidYMin slice"` как в файле.
- Идентификаторы внутри SVG (`g0…`, `hl0…`, `mp`, `mfade` и т. п.) сделай уникальными через `useId()` (префикс к каждому id и ссылкам `url(#…)` / `href="#…"`), потому что SVG рендерится дважды (десктоп и телефон переключаются классами `hidden xl:block` / `xl:hidden`).
- Анимация движущихся точек остаётся SMIL (`animateMotion`, `animate`), как в файле. Всем движущимся кружкам добавь класс `hero-flow` и в `globals.css`: `@media (prefers-reduced-motion: reduce) { .hero-flow { display: none; } }`.

## Расхождения (не придумывать, описать в PR)
1. **Цвет главных кнопок.** Макет делает главные кнопки зелёными (`primary`), а в проекте главное действие в контенте синее (`cta`, #1C608A; в шапке `cta` не используется). На главной все сплошные кнопки (hero, «Найти», «Подать объявление») делай `primary`. Это расхождение с остальным сайтом (формы, фильтры остаются синими): **не меняй `--cta` сам**, перечисли в PR; смена токена на весь сайт решение владельца.
2. **Рубрики без `slug`.** `RubricResponse` в OpenAPI содержит только `id`, `name`, `categories`. Сопоставление с конфигом идёт по названию (хрупко: переименование в базе отключит плитку). Предложение владельцу: добавить `slug` в бэкенд. У рубрики нет своей страницы, поэтому плитка и кнопка «Смотреть каталог» ведут на первую категорию рубрики; это временное решение, опиши в PR, как поступил.
3. **Поиск.** В шапке поиск это иконка с оверлеем, в hero отдельное поле: функционально они дублируют друг друга, оба неактивны до backend#205 и #206.
4. **Футер** добавляется во все страницы сайта (см. раздел 6).
5. Если `searchListing` без `text` и `sort` ведёт себя иначе, чем в OpenAPI (не «сначала новые», 422), остановись и опиши.
6. Данные города для карты демонстрационные (раздел 4).
